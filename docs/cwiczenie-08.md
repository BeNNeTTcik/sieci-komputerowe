# Ćwiczenie 8: Routing statyczny wewnątrz pary

*Część II — Zajęcia praktyczne*

## I. Wprowadzenie

Konfiguracja **tras statycznych** zapewniających pełną łączność IP między wszystkimi podsieciami pary.

<!-- 💡 Tu możesz wstawić diagram, np.: ![Diagram](/img/cwiczenie-08-diagram.svg) -->

## II. Zadania do wykonania

1. Trasy statyczne na R1-X do podsieci za R2-X.
2. Trasy statyczne na R2-X do podsieci za R1-X.
3. Trasa domyślna tam, gdzie zasadne.
4. Weryfikacja: show ip route, ping/traceroute.

## III. Podsumowanie

Pełna łączność IP osiągnięta wyłącznie routingiem statycznym.
