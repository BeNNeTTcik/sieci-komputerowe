Serwer `SRV1` udostępnia najważniejsze usługi sieciowe. Każdą z nich obejrzysz w szczegółach pakietu:

| Usługa | Protokół | Port | RFC |
|---|---|---|---|
| Adresacja | DHCP | UDP 67/68 | [2131](https://www.rfc-editor.org/rfc/rfc2131) |
| Nazwy | DNS | UDP 53 | [1035](https://www.rfc-editor.org/rfc/rfc1035) |
| Strony WWW | HTTP / HTTPS (TLS 1.3) | TCP 80 / 443 | [9110](https://www.rfc-editor.org/rfc/rfc9110), [8446](https://www.rfc-editor.org/rfc/rfc8446) |
| Pliki | FTP (EPSV) | TCP 21 + port danych | [959](https://www.rfc-editor.org/rfc/rfc959), [2428](https://www.rfc-editor.org/rfc/rfc2428) |
| Poczta | SMTP, POP3 | TCP 25, 110 | [5321](https://www.rfc-editor.org/rfc/rfc5321), [1939](https://www.rfc-editor.org/rfc/rfc1939) |
| Czas | NTP | UDP 123 | [5905](https://www.rfc-editor.org/rfc/rfc5905) |

:::tip[Do sprawdzenia]

Otwórz tę samą stronę przez HTTP i HTTPS. W którym przypadku w szczegółach pakietu widać treść strony? A hasło FTP?

:::
